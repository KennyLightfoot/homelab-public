# Self-hosted ticketing — osTicket home lab

I deployed osTicket with Docker Compose and use it to log and resolve incidents from my home lab. This gives the infrastructure work a place to track issues as tickets and practice support documentation.

## Work completed

- Used the ticketing system to record and resolve lab incidents.
- The recorded container inventory includes osTicket and its MySQL database container.
