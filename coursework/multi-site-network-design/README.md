# Multi-site network design — WGU coursework

I designed a three-site network and revised its addressing plan to resolve overlapping IP ranges. I then built the topology in GNS3 using OPNsense firewalls. This project covers network design and topology construction.

## Design scope

| Element | Scope |
|---|---|
| Locations | Three sites |
| Segmentation plan | Four VLANs per site |
| Perimeter design | A DMZ |
| Inter-site design | Hub-and-spoke IPsec VPN |
| Simulation | GNS3 topology using OPNsense firewalls |

## Work completed

- Designed the site layout, segmentation plan, and inter-site VPN topology.
- Re-addressed the sites to resolve an IP overlap in the design.
- Built the corresponding GNS3 topology with OPNsense firewalls.

## Result and boundary

The deliverable was a network design and simulated topology. End-to-end routing, working VPN tunnels, and successful traffic tests are not documented results of this project. The VLAN plan belongs to the coursework design; it does not describe the physical home switch, which uses a flat/default network.

This public summary excludes the full coursework submission and raw GNS3 project. It provides the project scope and completed work without presenting the design as an operational network.
